# CC 작업 지시서 — 보안 게이트 (16~20강) 슬라이드 채우기 · 첫걸음 완결

> 위치: `AI_First_Step/order/보안게이트_슬라이드_지시서.md` · **AI_First_Step에서 실행.**
> **장수는 배열이 정본** — 실개수 세어 보고(하한 12장). 본진 무변경(⑥ 헌법 조항만 양쪽).
> 이 상자로 첫걸음 20강 콘텐츠가 완성된다.

---

## 톤 가이드 (보안 게이트 = 겁주지 않는 상자)

- **최우선 원칙: 공포 마케팅 금지.** 보안·저작권·괴담은 잘못 다루면 "그래서 쓰지 말라는 거네"로 끝난다. 전부 **"이것만 지키면 마음 놓고 쓴다"** 프레임.
- 18강(괴담과 진실)은 **논쟁적 사안** — 사실과 과장을 가르되 단정하지 않고, 관점이 갈리는 지점은 양쪽을 병기한다.
- 김주임 서사 완결: 능숙한 사용자 → **규칙을 아는 사용자** → 20강에서 다음 여정으로.
- `[P]` 태그 필수(사례·생각해보기·과제).

## 작업 순서

1. 16~20강 placeholder를 아래 배열로 교체(스키마 매핑, `[P]` 주석).
2. 도식 2종(E6·E7) 라이트 톤 제작 → assets/.
3. ⑥ tone-keeper 헌법 조항 명문화(양쪽 저장소).
4. `npm test` → 파이프라인 4종 가동 → `order/검증리포트_보안게이트_*.md` 저장.
5. `docs/콘텐츠_현황.md` 갱신(첫걸음 20강 전부 완료로).
6. 커밋. **push 없음** — 마감은 release-manager로 별도.

## 신규 도식 2종 (라이트 톤 · E 시리즈)

**E6 `assets/diagram-input-check.svg` — 넣기 전 신호등 (16강)**
가운데 [입력창 💬] 앞에 신호등 3단: 🟢 초록 [공개 정보·내 메모·일반 질문 — 그냥 넣기], 🟡 노랑 [업무 문서 — 이름·금액 지우고 넣기], 🔴 빨강 [고객 개인정보·계약서·비밀번호 — 넣지 않기]. 보조 문구: "빨간불만 피하면, 나머지는 마음 놓고".

**E7 `assets/diagram-ai-journey.svg` — 첫걸음에서 다음으로 (20강)**
좌→우 상승 길: [🏢 로비 — 알아차리기] → [💬 미팅룸 — 대화하기] → [💻 내 책상 — 써먹기] → [🔐 보안 게이트 — 안전하게] → 그리고 길 끝에서 갈라지는 새 길 [🚀 AX — 일하는 방식 바꾸기](점선·다음 여정 표시). 보조 문구: "도구를 익혔다면, 다음은 방식이다".
