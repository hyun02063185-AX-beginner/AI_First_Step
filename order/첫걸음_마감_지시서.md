## ① E7 도식 — AX 노드 색 교체 (헌법 조문 유지)

**판단**: tone-keeper 지적 수용. `#B45309`(주황·갈색)는 경고가 아니라 강조색이라 "의미색 예외" 조문과 어긋난다. **조문을 넓히지 않고 색을 바꾼다.**

**교체 방향**: E7의 AX 노드(다음 여정)를 **사유의 방(AX 사이트) 브랜드 골드 계열**로.
- 본진 스킨의 골드 값(예: `#D8B27A` 계열 — 실제 값은 본진 `sayu` 스킨 변수에서 확인해 사용)
- 의미: "다음 여정 = AX 과정"이 **저쪽 사이트의 색**으로 표현돼, 제품군 관계가 시각적으로 드러난다.
- 나머지 네 구역 노드(로비·미팅룸·내 책상·보안 게이트)는 기존 첫걸음 팔레트 유지 — **대비가 곧 메시지**.
- 라벨·점선 처리 등 기존 구성은 유지. 변경 후 3스킨에서 대비 확인.

> 헌법(의미색 예외)은 **개정하지 않는다** — 신호등류에만 적용되는 좁은 조문으로 유지.

## ③ release-manager 가동 — 두 저장소 마감

**AI_First_Step (주 마감):**
1. 마감 전 점검: 미커밋 변경·브랜치 상태 확인
2. `npm test` + qa-runner 회귀 1회
3. boundary-keeper 1회 — 이번 라운드 변경이 경계를 지켰는지, 본진 동기화 누락 없는지
4. **계획 요약 보고 → 사용자 승인 대기** (병합·태그·push 전 필수 게이트)
5. 승인 후: 태그 `v1.0-curriculum` (메시지 예: "AI 첫걸음 20강 콘텐츠 완결 — 256장·도식 7종·4상자 에이전트 검증 통과") → **push 1회**(main + 태그)

**AX_Lecture (규범 동기화분 마감):**
6. 쌓인 규범 커밋(헌법 개정 3회분·공유규범 분류·콘텐츠 현황 분리·이식 이력) 상태 확인 → `npm test` 통과 확인
7. 태그 없이 **push 1회** (콘텐츠 변경 없음 — 태그는 다음 마일스톤에서)

> 두 저장소 모두 **push 1회씩**으로 마감(Netlify 배포 크레딧 무관하나 관례 유지).
