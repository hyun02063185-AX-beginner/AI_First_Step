## ① 06강 서수 충돌 해소 (quote 양보)

**문제**: 06강 제목·구역 테마·07/10강 콜백은 "첫 대화"인데, quote 코멘트만 "두 번째부터의 이야기"라 같은 사건에 서수가 둘.

**결정**: **"첫 대화" 표현을 정본으로 유지**(미팅룸=첫 만남이라는 구역 이름값 + 타 강 콜백 파급 회피). 승격 프레임의 핵심은 서수가 아니라 "제대로 쓰기 시작"이므로, **quote 코멘트에서 서수를 걷어낸다.**

06강 quote 슬라이드의 `by`만 교체:

```js
{ type: 'quote',
  text: '가장 어려운 프롬프트는\n첫 번째 프롬프트다',
  by: '그 문턱은 넘었다 — 오늘부터는 제대로 쓰는 이야기' }
```

- `text`(본문 인용)는 유지. **`by`만 교체.**
- 06강 내 다른 슬라이드(cover·big·사례·과제·closing)는 이미 승격 프레임으로 정리돼 있으므로 **무변경**.
- 07·10강의 "첫 대화" 콜백도 **무변경**(정본 표현).

## ② 03강 사례 소재 교체 (자기소개서 → 업무 소재)

**문제**: 재직자 맥락에서 "자기소개서"는 결이 어긋남(낮은 심각도).

**결정**: 04강 특기(초안)·05강 용어와 이어지는 **업무 소재**로 교체. 사례 슬라이드의 items 첫 두 항목만 교체(제목·부제·나머지 항목 유지):

```js
// 03강 사례 슬라이드 — items 1·2번 항목만 교체
'"팀 워크숍 공지 첫 문장 좀 써줘" — 될 리가 있나 싶었다',
'3초 만에 제법 그럴듯한 문장이 나왔다',
// (3·4번 항목 "헐"·"마법이 아니라…"은 그대로 유지)
```

> 03강 과제("회식 공지 한 줄 시켜보기")와 소재 결이 같아져 강의 내 정합도 상승 — 과제는 무변경.
