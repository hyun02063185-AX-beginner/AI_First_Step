## ① 06강 서사 충돌 수정 (콘텐츠)

**문제**: 03강(첫 대화의 "헐")·04강(경조휴가 흑역사)에서 이미 AI와 대화한 김주임인데, 06강이 "처음으로 말을 겁니다"로 소개 — 시간선 모순.

**해결 방향**: "처음"을 지우는 게 아니라 **승격 프레임**으로. 로비의 김주임은 *호기심으로 몇 번 찔러본* 단계, 06강은 *대화 상대로 제대로 삼기 시작하는* 단계. 사례는 **로비 이전 회상**으로 시점을 명시해 살린다.

**아래 슬라이드만 교체**(나머지 06강 슬라이드는 그대로 유지):

- **cover** subtitle: `'화면 열고, 아무거나 물어보기'` → `'찔러보기에서, 제대로 쓰기로'`
- **big(2번째)**:
```js
{ type: 'big', word: '이제 제대로\n말을 겁니다',
  sub: '몇 번 찔러봤다면(로비) — 오늘부터는 대화 상대로' }
```
- **bullets '어디서 시작하나'** subtitle: `'문은 생각보다 가깝다'` → `'이미 열어봤다면, 그 창에서 이어가면 된다'`, items 첫 항목을 `'로비에서 열어본 그 챗봇 — 계속 씁니다(10강에서 정식으로 고름)'`로 교체(나머지 3개 유지)
- **bullets '첫 마디, 뭐라고 하지?'** → 제목 `'오늘의 말 걸기'`, subtitle `'가볍게 다시 시작하는 3가지'` (items 유지)
- **사례 슬라이드** — 시점 명시로 수정:
```js
{ type: 'bullets', title: '사례 · 커서만 깜빡이던 5분',    // [P]
  subtitle: '김주임이 처음 챗봇을 열었던 날 (03강 그 전날)',
  items: [
    '입력창 앞에서 5분을 망설였다 — "뭐라고 하지, 이상하게 보이면 어쩌지"',
    '결국 친 첫 마디: "안녕"',
    '"안녕하세요! 무엇을 도와드릴까요?" — 어이없게 친절한 답이 왔다',
    '망설인 5분이 제일 어려웠다. 그 뒤로는 물어보는 게 일상이 됐다'
  ] }
```
- **quote**:
```js
{ type: 'quote',
  text: '가장 어려운 프롬프트는\n첫 번째 프롬프트다',
  by: '그건 이미 지났다 — 오늘은 두 번째부터의 이야기' }
```
- **한 장 정리 과제** 마지막 항목: `'📝 과제: 지금(또는 퇴근 전) 첫 마디를 던져보세요 — "안녕"도 훌륭합니다'` → `'📝 과제: 오늘 업무 중 궁금한 것 하나를 그 창에 물어보세요 — 이번엔 업무로'`
- **closing** title `'첫 마디를 던졌다'` → `'제대로 시작했다'`

> 06강 이후(07~10강)는 수정 불필요 — 확인만.

## ② 톤앤매너 헌법 개정 (03강 오해 셋)

**판단**: 03강은 "여기서 미리 심는 주의 하나"(⚠ 씨앗)가 오해 교정 자리를 대신하는 **의도된 변형**. 콘텐츠는 유지하고 헌법을 정밀화한다.

`docs/톤앤매너.md` (첫걸음판·AX판 **양쪽**) 규격 조항 개정:

> **흔한 오해 셋** — 원칙적으로 각 강에 포함한다. 단, 해당 강이 오해 교정과 같은 목적의 **대체 장치**(예: 다음 강으로 넘기는 ⚠ 경고 슬라이드, 잘못된 사용 사례 슬라이드)를 갖고 있으면 생략할 수 있다. 생략 시 그 강에 대체 장치가 실제로 존재해야 하며, 한 상자에서 2개 강 이상 생략은 편차로 본다.

- tone-keeper가 이 조문을 그대로 적용하도록(생략 강의 대체 장치 존재 여부를 검사) 정의문에 반영 필요하면 최소 수정.

## ③ 미팅룸 전체 검증 (첫 파이프라인 실전)

①② 반영 후, `docs/에이전트_운영.md`의 표준 파이프라인을 미팅룸(06~10)에 적용:

1. `npm test` — 콘텐츠 린트 통과 확인(06강 수정 반영)
2. **persona-reviewer** — 06~10강 × 김주임 관점. **시간선 정합**을 중점 항목으로 지정(로비→미팅룸 전체 서사가 이제 어긋나지 않는지)

4. **qa-runner** — 렌더·티저 체인(05→06→…→11)·도식 E3·3스킨·375px·콘솔
