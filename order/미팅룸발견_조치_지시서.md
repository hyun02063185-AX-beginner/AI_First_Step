## ① 로비 잔여 시간선 정리 (03·05강)

06강을 "승격 프레임"으로 바꾼 결과, 로비에 남은 "처음" 표현들이 어긋난다. **아래 지정 슬라이드만 교체.**

### 03강 사례 슬라이드

초점을 "첫 말 걸기"에서 **"생성형 원리를 눈으로 확인한 순간"**으로 이동 (03강은 원리 강의):

```js
{ type: 'bullets', title: '사례 · 반신반의로 시켜본 날',    // [P]
  subtitle: '김주임이 원리를 눈으로 본 순간',
  items: [
    '"자기소개서 첫 문장 좀 써줘" — 될 리가 있나 싶었다',
    '3초 만에 제법 그럴듯한 문장이 나왔다',
    '"헐" — 그날 저녁 내내 이것저것 시켜봤다',
    '마법이 아니라, 방금 배운 그 게임(그럴듯한 다음)이었다'
  ] }
```

### 05강 closing 티저

`'로비 투어 끝. 미팅룸으로 갑니다 — 처음으로 AI와 직접 대화를.'` 부분을 아래로 교체(제목은 유지):

```js
{ type: 'closing', title: '준비 끝 — 이제 제대로 쓸 차례',
  teaser: '로비 투어 끝. 미팅룸으로 갑니다 — 찔러보기에서 벗어나, 대화 상대로. (다음 구역: 미팅룸 — 첫 대화 시작하기)' }
```

> 04강 경조휴가 사례는 "이미 써본 사람"의 실수라 새 시간선과 정합 — 무변경.
> 03강 과제("회식 공지 한 줄 시켜보기")도 그대로 유효.

## ② 10강 규격 보강 (11장 → 하한 충족)

미팅룸 수료 강이므로 **되짚기 슬라이드 1장**을 추가한다. 위치: 기존 `'한 장 정리 + 미팅룸 수료'` **바로 앞**.

```js
{ type: 'bullets', title: '미팅룸에서 생긴 변화',
  subtitle: '들어올 때와 나갈 때',
  items: [
    '들어올 때: 입력창 앞에서 뭘 쓸지 몰랐다',
    '지금: 재료 세 가지(상황·대상·모양)를 챙겨 묻는다',
    '들어올 때: 첫 답이 별로면 창을 닫았다',
    '지금: "더 짧게" 한마디로 이어간다 — 그리고 밖으로 나갈 건 확인한다'
  ] }
```

- 추가 후 10강 장수를 세어 보고(하한 12장 충족 확인).

## ③ 엔진_경계.md — 제4 분류 신설 (양쪽 저장소)

boundary-keeper 발견: `docs/*.md`·`.claude/agents/*.md`가 기존 분류(공유 엔진 / 사이트 고유)에 안 걸린다. **"공유 규범(Shared Norms)"** 절을 신설:

- **대상**: `docs/UX_원칙.md` · `docs/엔진_경계.md` · `docs/에이전트_운영.md` · `.claude/agents/*` · `tests/` 공통 골격
- **성격**: 코드가 아니지만 **양쪽 저장소가 동일해야 하는** 규범. 한쪽에서 개정하면 다른 쪽에 동기화한다.
- **예외(사이트별로 다를 수 있는 규범)**: `docs/톤앤매너.md`(첫걸음판/AX판), `docs/운영자_치트시트.md`, 린트 상수 — **"동기화 대상이지만 사이트별 조정 허용"**으로 명시.
- **절차**: 규범 개정 시 ① 어느 쪽에서 개정했는지 ② 상대 저장소 반영 여부를 이식 이력에 기록.
- boundary-keeper 정의문에 이 분류를 검사 항목으로 추가(규범 파일 변경 시 "상대 저장소 동기화 필요" 플래그).
