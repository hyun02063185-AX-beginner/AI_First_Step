# CC 작업 지시서 — 연습 책상 (AI 첫걸음 실습 공간)

> 위치: `AI_First_Step/order/연습책상_지시서.md` · **AI_First_Step에서 실행.**
> **권장 모델: 엑스트라** — 신규 공간(씬+데이터+연동) 설계 구현.
> 설계 원칙: **앱이 AI를 대신하지 않는다.** 모든 실습은 수강생 "자기 챗봇"에서 하고, 앱은 안내·조립·기록을 맡는다(교육 목표 = 자기 챗봇 습관, API 비용 0).
> 진단실과의 대칭: AX = 진단해서 조직 제안서 / **첫걸음 = 연습해서 개인 시작 키트.**

---

## 공간 개요

- 이름: **연습 책상** (첫 출근 은유 유지)
- 진입: 입장 화면에 진단실과 같은 위계의 부 버튼 — `📒 연습 책상` (강의실 입장보다 좁게, ① 버튼 다이어트와 동일 규격)
- 해금: **Lv1부터 상시 노출**(진단실과 달리 게이팅 없음 — 실습은 1강부터 병행하는 것이므로). `SITE_CONFIG.practiceDesk: true`로 제어(엔진 config 주도).
- 구성 3존: ① 미션 스탬프판 ② 프롬프트 조립대 ③ 나의 시작 키트

## 존① — 미션 스탬프판

- 20강의 📝 과제를 데이터로 추출해 한 화면에 카드 그리드로(구역 4색 그룹핑).
- 각 미션 카드: 과제 문구 + "내 챗봇에서 해보세요" 안내 + **[완료 스탬프]** 버튼(자기 신고식 — 검증 장치 없음, 부담 없는 체크).
- 스탬프 상태 localStorage 저장. 진행률 표시(예: "7/20 미션").
- 미션 데이터는 **data.js의 과제 슬라이드에서 파생하지 말고 별도 미션 배열로 정의**(과제 문구를 미션용으로 다듬을 수 있게 — 초기값은 각 강 📝 과제와 동일하게 작성, 강 번호 연결 유지).
- 강의를 아직 안 본 미션도 잠그지 않음(순서 자유) — 단 카드에 해당 강 번호 표시("06강에서 배웠어요" → 클릭 시 해당 강으로 이동).

## 존② — 프롬프트 조립대

07강 "재료 3가지"의 인터랙티브 실습:
- 입력 3칸: **상황 / 대상 / 원하는 모양** (placeholder에 07강 예시)
- 채우면 하단에 완성 프롬프트가 실시간 조립됨(자연스러운 한 문단으로).
- **[복사] 버튼** + 안내: "복사해서 내 챗봇에 붙여넣어 보세요" — 앱은 여기까지, 실행은 자기 챗봇.
- (선택) 자주 쓰는 업무 템플릿 3종 프리셋: 메일 다듬기(11강)·요약 요청(12강)·아이디어 벽치기(13강) — 누르면 3칸이 예시로 채워짐.
- 조립한 프롬프트를 **[내 키트에 저장]** — 키트(존③)의 프롬프트 모음으로.

## 존③ — 나의 시작 키트 (수료 산출물)

19·20강의 "메모장" 개념의 실물. 카드 한 장으로 조립:
- **나의 단짝 챗봇** — 직접 입력(10강 과제 연동)
- **나의 프롬프트 모음** — 존②에서 저장한 것 목록(+직접 추가 가능)
- **나의 신호등 규칙** — 16강 "지울 것 목록"을 직접 입력(간단 리스트)
- **미션 진행** — 존① 스탬프 요약(n/20)
- 완성도에 따라 카드가 채워지는 시각 연출(진단실 제안서 문법 재사용).
- **[이미지로 저장/인쇄]** 수준의 내보내기(진단실 제안서와 동일 방식 재사용 — 새 방식 개발 금지).

## LMS 연동

- 이벤트 추가(코드 있을 때만·fail-silent, 기존 패턴):
  - `mission_stamp` { lectureId } — 스탬프 시(중복 방지: 같은 미션 재전송 안 함, 해제는 전송 안 함)
  - `kit_updated` { fields: [...], missionCount } — 키트 항목 저장 시(과도 전송 방지: 세션당 항목별 1회)
- track 화이트리스트·aggregate 반영(코드별 최신 키트 상태·미션 수), 대시보드 수강생 상세 레이어에 "미션 n/20 · 키트 항목 m/3" 한 줄 추가(새 섹션 신설까지는 불요 — 최소 표시).
- 하네스: 신규 이벤트 계약 테스트 추가, 미션 배열 린트(20개·강 번호 유효) 추가.
