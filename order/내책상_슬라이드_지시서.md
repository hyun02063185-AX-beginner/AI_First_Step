> **장수는 배열이 정본** — 실개수 세어 보고(헌법 하한 12장 확인). 본진 무변경.
> 톤앤매너 헌법·페르소나 가이드 준수. `[P]` 태그 필수(이 상자는 페르소나 의존도 최고).

---

## 톤 가이드 (내 책상 = 써먹는 상자)

- 미팅룸이 "대화할 줄 안다"였다면, 내 책상은 **"오늘 업무에 쓴다"**. 매 강의가 당장 써먹을 것 하나를 남긴다.
- 김주임은 이제 능숙해지는 중 — 망설임 서사는 끝. **"이렇게도 되네" 발견**과 **작은 실수 교정**이 사례의 축.
- 미팅룸에서 배운 것(재료 3가지·이어가기·확인)이 매 강의에서 **실제로 쓰이는 장면**을 보여줄 것.
- 페르소나 의존 슬라이드(사례·생각해보기·과제)에 `// [P]`.

## 작업 순서

1. 11~15강 placeholder를 아래 배열로 교체(스키마 매핑, `[P]` 주석 포함).
2. 도식 2종(E4·E5) 라이트 톤 제작 → assets/.
3. `npm test` → 파이프라인(persona-reviewer·tone-keeper·qa-runner·boundary-keeper) 가동 → 보고서 `order/검증리포트_내책상_*.md` 저장.
4. 커밋 (예: "내 책상 11~15강 콘텐츠 + 도식 2종"). **push 없음.**
