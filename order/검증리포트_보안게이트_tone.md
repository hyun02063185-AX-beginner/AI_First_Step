## §7 자기 점검 (판정 대상 범위 확인)

`docs/콘텐츠_현황.md`는 보안 게이트를 아직 "⏳ placeholder"로 표시 중(갱신 전이라 당연함, Task 44에서 처리 예정). `js/data.js`가 실제로는 완결돼 있어 이를 근거로 감사를 진행했다. **[높음] 발견**: `콘텐츠_현황.md` 갱신이 아직 실행되지 않음 — 지시서 완료 체크리스트 항목.

## 조문별 위반/편차

### §1 규격
- 실개수: 16~20강 모두 13장. 위반 없음.
- **[높음] 20강 — "흔한 오해 셋" 및 대체장치 모두 없음.** §1 예외 조항(대체 장치 필요)에 따르면 생략 시 ⚠ 경고류·잘못된 사용 사례 같은 대체 장치가 있어야 하는데, 20강엔 그런 슬라이드가 전혀 없다(정리·회고 위주 구성). 명확한 위반.
- **[중간] 20강 — "생각해보기" 슬라이드 누락.** 16·17·18·19강은 모두 있으나 20강만 없음(§1엔 이 항목 예외 조항 자체가 없음).
- 18강은 "흔한 오해 셋" 타이틀 슬라이드는 없지만 괴담①~④ 섹션이 "맞는 부분/과장된 부분"을 명시적으로 가르는 구조라 대체 장치로 인정 — 통과 처리.
- 18강(통과)·20강(위반) 두 건이 생략에 해당 — **한 상자에서 2개 강 생략 = §1 "편차" 기준에 걸림**.
- 티저 체인: 16→20 전부 정확, 20강은 "AX 과정" 예외 형태로 정확히 마무리. 위반 없음.
- 훑기 자산: 16~20강 모두 충족. 위반 없음.

### §2~§4
위반 없음. 어투·용어·페르소나(`slidesVariants` 01강 1건뿐) 전부 통과.

### §5 도식
- 배경·잉크·기존 3색(청록/마젠타/보라) 사용은 규정대로. 카드형 처리도 준수.
- **[중간] 팔레트 외 색상 도입.** `diagram-input-check.svg`(신호등 빨강/노랑/초록), `diagram-ai-journey.svg`(AX 노드 주황 `#B45309`)가 §5 명시 5색 밖의 색을 새로 씀. 신호등 개념·보안게이트 box accent(`#047857`)와의 시각적 일치를 위한 의도적 선택으로 기능적으로 정당하나, E1~E5는 예외 없이 코어 5색만 사용해온 전례에서 이탈.

### §6 금지 사항
- 제품 서열화·공포 마케팅·근거 없는 수치: 전부 위반 없음.
- **18강 논쟁적 사안 병기 여부(특별 요청)**: 괴담②는 "전문가들 사이에 미래 위험을 두고 논쟁이 있다"를 명시적으로 인정한 모범적 병기. 괴담①(일자리)은 같은 수준의 명시적 "전문가 이견" 언급 없이 자체 결론(구성 변화론)에 안착 — §6 명백 위반은 아니나(수치·과장 없음) 괴담②보다 병기 균형이 약함. 낮음~중간, 판단 여지 있음.

## 일관성 편차 (조문 위반은 아니지만)
- "흔한 오해 셋" 처리 형식: 16·17·19강 전용 슬라이드, 18강 괴담 섹션 대체(통과), 20강 없음(위반) — 강마다 형식 갈림.
- "생각해보기" 유무: 16~19강엔 있고 20강만 없음.
- 사례 화자 명명: 전체 20강 중 무명 화자는 02강·17강 단 둘 — 17강만 보안 게이트 상자 안에서 유독 무명 처리(§4 "화자 성장선" 원칙과 살짝 어긋남, 명백 위반은 아님).
- 도식 팔레트 확장은 E6·E7만의 새 관례 — 보안 게이트 box accent(`#047857`)도 §5 팔레트 밖 색(도식 파일 문제는 아니라 참고만).

## 헌법이 낡았다면 개정 제안
- **캡스톤(회고형) 강 예외 조항 부재**: 20강처럼 새 내용 없이 회고만 하는 마지막 강에는 "흔한 오해 셋"·"생각해보기"가 자연스럽게 생기기 어렵다. 티저 체인 조항의 "마지막 강 예외" 선례처럼, §1에 "회고형 강은 회고형 대체 슬라이드로 갈음 가능" 예외 신설을 제안 — 단, 헌법을 완화하는 방향이라 신중히 결정할 사안.
- **§5 "의미론적 보조색" 허용 여부 불명확**: 신호등류 개념이 요구하는 의미색을 코어 5색 엄수 대신 보조적으로 허용할지 결정 필요 — 지금은 문언과 실제(E6/E7)가 이미 어긋나 있어 방치하면 반복 지적될 것.
- **box accent 색상 규칙이 §5에 없음**: 로비·미팅룸·내 책상 accent는 우연히 코어 팔레트 안이지만 보안 게이트만 밖 — 의도인지 누락인지 문서만으로 판단 불가.
