# CC 작업 지시서 — 공유 슬라이드 판 종속 조치 + 「박선배」 20강 완결 묶음

> 위치: `AI_First_Step/order/박선배_완결_지시서.md` · **AI_First_Step에서 실행.** 권장 모델: 높음. 연속 1회 실행.
> Part A = 최사장 검증 발견 4건 조치(헌법 §2⑦ 신설 포함). Part B = 박선배(student) 20강 전체. Part C = 미션·마감.
> 원칙: `slidesVariants.student` 부분 오버라이드, 기본판·owner 무변경(Part A의 지정 오버라이드 제외), 회사 용어 금지.

## Part A · 공유 슬라이드 판 종속 조치

### A-0. 헌법 §2⑦ 신설 (톤앤매너 첫걸음판 — AX판은 해당 구조 없음, 확인만)

> **⑦ 공유 슬라이드의 판 종속 참조** — 개념·정리 슬라이드는 공유가 원칙이나, 슬라이드가 (a) 특정 판의 화자·사례를 호명하거나 (b) 특정 신분(직장인 등)을 전제한 문구를 담으면, **해당 슬라이드에 한해** 각 판이 최소 범위로 오버라이드한다. 논지·구조는 유지하고 참조·전제만 바꾼다.

### A-1. 09강 "김주임" 호명 (환각 모습 슬라이드)

- **owner 오버라이드**: 해당 항목을 `'가게 사정을 물으면 "일반적인 가게" 기준으로 창작 (04강 세금 사례!)'`로 교체(나머지 항목 기본판 복사).
- **student 오버라이드**: `'우리 학교 사정을 물으면 "일반적인 대학" 기준으로 창작 (04강에서 곧 봅니다)'` → Part B의 04강 사례(수강신청)와 연결되게 `'(04강 수강신청 사례!)'`로.

### A-2. 16강 정리+과제 — owner 전면 오버라이드 (기존 "과제 줄만" 예외)

```js
{ type: 'bullets', title: '한 장 정리 + 오늘의 과제',
  subtitle: '이것만 기억하세요',
  items: [
    '넣기 전 3초: "이게 밖으로 나가도 되나?"',
    '빨간불 4가지만 외운다 — 나머지는 노란불(지우고) 또는 초록불',
    '가게의 규칙은 사장님이 정한다 — 오늘 세운 신호등이 그 규칙이다',
    '📝 과제: 자주 넣는 자료 1종에서 "지울 것" 목록을 만들어보세요'
  ] }
```

### A-3. 12강 owner 생각해보기 "본사 공지" 수정

해당 항목만: `'(정책 안내문, 본사 공지)'` → `'(지원사업 안내문, 위생 교육 자료)'`

### A-4. "회사 규칙 우선" 문구 3곳 — owner 항목 교체 (슬라이드 복사+한 줄 교체 방식)

- **06강 '어디서 시작하나'**: `'회사 계정 규칙이 있으면 그걸 우선(16강에서 자세히)'` → `'가게에선 정해주는 사람이 없다 — 내 기준은 16강에서 세운다'`
- **10강 '고르는 기준 세 가지'**: `'① 회사가 정한 게 있나? → 그걸 쓴다 (보안 규칙 우선, 16강)'` → `'① 이미 폰에서 익숙한 게 있나? → 거기서 시작 (안전 기준은 16강에서)'` — 뒤 항목 번호 문맥 자연스러운지 확인·미세 조정 허용
- **16강 '회사 규칙이 먼저다' 슬라이드**: owner 전면 오버라이드 —
```js
{ type: 'bullets', title: '사장님 가게의 규칙은 사장님이 만든다',
  subtitle: '정해주는 사람이 없다는 것의 의미',
  items: [
    '직장인은 회사 규칙을 따르면 되지만, 사장님은 스스로 정해야 한다',
    '오늘의 신호등이 그 규칙의 시작 — 종이에 써 붙여도 좋다',
    '알바생과 함께 쓰기 시작하면, 그 규칙을 같이 지킨다',
    '"몰래"가 없는 대신 "기준 없이"가 위험하다 — 기준만 세우면 자유다'
  ] }
```

## Part B · 박선배 20강 오버라이드

**페르소나**: 박선배 — 3학년 복학생. 과제·팀플·공모전·알바, 취준 초입. **정서 축: 이미 슬쩍 쓰면서 찜찜했던 사람 → 숨어 쓰지 말고 떳떳하게 잘 쓰기.** (17강이 이 판의 심장.) 어휘: 교수님·조교님·팀플·조모임·과제·리포트·공모전·자소서·단톡·도서관. 회사 용어 금지.
