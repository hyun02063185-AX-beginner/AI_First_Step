# CC 작업 지시서 — 최사장 완결 묶음 (06~20강 + 04강 결 수정 + 연습 책상 페르소나 + 무대뒤.판)

> 위치: `AI_First_Step/order/최사장_완결_지시서.md` · **AI_First_Step에서 실행.** 권장 모델: 높음.
> 최사장 톤은 로비에서 승인됨 — 잔여 전체를 한 번에 작업한다. 4개 파트를 **연속 1회 실행**으로.
> 원칙 동일: `slidesVariants.owner` 부분 오버라이드만, 개념·도식·big/quote·split 무변경, 회사 용어 금지(손님·리뷰·발주·상인회·알바생·마감).

---

## Part 1 · 04강 사례 결 수정 (기존 owner 오버라이드 교체)

"5년차가 부가세 시기를 모름" 어색 → **베테랑이라 걸리는 질문**으로:

```js
{ type: 'bullets', title: '사례 · 잘못 시킨 날',
  subtitle: '최사장의 아찔했던 순간',
  items: [
    '"작년에 바뀐 세금 제도, 우리 가게도 해당돼요?"라고 물었다',
    '"네, 해당됩니다"라는 그럴듯한 답 — 그대로 믿고 서류를 준비할 뻔했다',
    '세무사에게 확인하니 우리 유형은 반대였다 — AI는 최신 제도도, 내 사업자 등록도 본 적이 없다',
    '교훈: 특기(초안·요약)를 시켰어야 했는데, 약점(최신·내 사정)을 시켰다'
  ] }
```

## Part 2 · 06~20강 오버라이드 (각 강: 사례 + 생각해보기 + 과제 줄)

> 형식: 사례·생각해보기는 전체 슬라이드 교체, "한 장 정리+과제"는 **과제 줄만** 교체(정리 3항목은 기본판 유지). 20강만 예외(아래 별도).

    '"안녕하세요! 무엇을 도와드릴까요?" — 어이없게 친절한 답이 왔다',
    '그날 깨달았다: 이제 밤 11시에도 물어볼 상대가 있다'

## Part 3 · 연습 책상 페르소나 대응

- `PRACTICE_MISSIONS`에 **페르소나별 문구 오버라이드** 지원(`variants: { owner: '...' }` 형태 — 구조는 CC가 desk.js 부담 보고 결정, slidesVariants와 같은 폴백 원칙: 없으면 기본 문구).
- **owner 미션 문구 = 이 지시서·로비 지시서의 owner 과제 줄과 동일하게** 20개 등록(강 번호 매핑 유지).
- desk.js가 활성 variant를 인식해 미션·(필요시 조립대 placeholder·프리셋 라벨도 점검해 어긋나면 함께) 표시. 존③ 키트는 공용 유지.
- student는 이번에 등록하지 않음(폴백으로 기본 문구 — 다음 차례).

## Part 4 · 히든코드 `무대뒤.판`
