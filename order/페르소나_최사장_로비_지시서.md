# CC 작업 지시서 — 페르소나판 「최사장」 로비 (01~05강)

> 위치: `AI_First_Step/order/페르소나_최사장_로비_지시서.md` · **AI_First_Step에서 실행.**
> 첫 페르소나 실콘텐츠. `slidesVariants.owner` 부분 오버라이드로만 작업 — **기본판(직장인) 무변경.**
> 권장 모델: 높음. 전제: 페르소나 variant 기반 완료(`?variant=owner`, 뱃지 'O').

---

## 페르소나 정의 (이 판 전체의 기준)

**최사장** — 동네에서 5년째 작은 카페를 운영. 40대. 컴퓨터는 포스기·배달앱 정도.

- **김주임과의 결정적 차이: 물어볼 사람이 없다.** 직장인은 선배에게 묻지만 1인 사업자는 혼자 결정한다. 그래서 최사장에게 AI는 도구이기 전에 **"24시간 물어볼 수 있는 상대"** — 이 판의 정서적 축.
- 시간이 가장 부족한 사람: 장사하며 홍보·발주·세무·응대를 다 한다. **"이걸 5분에 끝냈다"**가 가장 큰 감동 포인트.
- 어휘: 회사 용어(팀장·보고서·회의) 금지. 대신 손님·리뷰·발주·상인회·알바생·마감.
- 자주 나오는 장면: 배달앱 리뷰 답글, 인스타/블로그 홍보 문구, 신메뉴 아이디어, 휴무 안내, 발주·정산, 세무·지원금 확인.

## 작업 방식

1. **01~05강에서 페르소나 의존 슬라이드를 식별**한다 — 사례 / 생각해보기 / 한 장 정리+과제(과제 문구 포함). 기본판 주석에 `[P]`가 없으면 이번에 추가(렌더 무영향 확인).
2. 해당 슬라이드만 `slidesVariants.owner`에 오버라이드로 등록(기반 지시서에서 채택한 인덱스 또는 id 방식 그대로).
3. **개념·도식·big/quote·split 슬라이드는 오버라이드하지 않는다**(공유 자산 원칙 — 헌법 §2).
4. `?variant=owner`로 렌더 검증 후 커밋.

```js
  items: [

    '사진 보정 앱의 자동 밝기, 카드사의 이상거래 알림까지 — 전부 AI였다',

  ] }
```

**생각해보기 오버라이드**
```js

  subtitle: '30초만',

    '오늘 가게 일 하면서 만난 AI를 세 개만 꼽아보세요',
```

## 검증

- [ ] 기본 URL(직장인판): **완전히 기존과 동일**(오버라이드가 기본판에 0 영향)
- [ ] `?variant=owner`: 위 슬라이드만 최사장판, 나머지 전부 기본판 상속. HUD 'O' 뱃지. 세션 유지
- [ ] `?variant=student`(파일럿 샘플)·기본판 동시 정상 — 3판 공존 확인
- [ ] 오버라이드 슬라이드에 회사 용어(팀장·보고서·회의) 잔존 0건 — **전수 검색으로 확인**
- [ ] 이어보기·핵심훑기·완료판정이 variant와 무관하게 동작
- [ ] `[P]` 태그 부착 완료(01~05강), 렌더 무영향
- [ ] `npm test` 통과(변형 린트 포함), 콘솔 0건
- [ ] **persona-reviewer 1회 가동** — 관점: "동네 카페 5년차 자영업자". 위화감·용어·과제 실행 가능성 검증. 보고서 `order/검증리포트_최사장_로비.md` 저장. **발견은 보고만**
- [ ] 커밋. **push 없음**
